# Character Catalog (char-XX)

Referencia curada de nombres y rasgos jugables para los 37 avatares.

## Convenciones

- `characterId` del juego: `char-N` (sin cero a la izquierda, por compatibilidad actual del backend).
- Ruta de imagen: `/characters/png/char-XX.png` (con cero a la izquierda a dos digitos).
- Integridad obligatoria:
  - exactamente uno entre `IS_MALE` y `IS_FEMALE`
  - si `IS_BALD` entonces no puede tener rasgos de pelo
  - si no es calvo, debe tener exactamente una longitud y una textura de pelo
